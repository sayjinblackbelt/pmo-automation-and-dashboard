O projeto estava relacionado a uma área operacional destinada ao **armazenamento e abastecimento de diesel** em uma unidade industrial.

Foi identificada a necessidade de realizar adequações na infraestrutura existente, sendo necessária a estruturação de uma contratação para desenvolvimento de um **Projeto Executivo**.

A elaboração do projeto executivo deveria permitir transformar a necessidade de adequação em uma solução técnica detalhada, fornecendo uma base adequada para eventual etapa posterior de execução.
